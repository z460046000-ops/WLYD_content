本轮结论：中台检索、规则加载、并行组稿和持久化可执行；**完整对客方案与浏览器成功返回均未通过验收**。修复优先级为：①生成工具返回 JSON 合法、避免自动重复生成；②模型路由跟随会话选择；③长输入/长输出下的章节失败与缺章状态；④对外措辞、场景深度、审核项收敛。未重测首次上传、统一 `/retrieval/query`、500 MB 文件、用户身份映射、HTML/PPTX/PDF。
