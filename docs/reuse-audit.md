# 交接包复用边界

日期：2026-10-14。`sources/` 只用于核对协议与实现路径，不进入安装包，也不被运行时代码导入。

| 能力 | 本插件的处理 | 理由 |
|---|---|---|
| DSH 工具注册和 Cordis patch | 按公开插件接口重新注册独立命名空间 | 避免旧插件运行时耦合 |
| 文件识别与提取 | 独立适配器、逐文件状态、限额、原件摘要 | 保留可验证技术路径，不复制旧流程和旧文案 |
| 项目绑定、上传、解析状态、hybrid-search | 按交接包的接口契约重新实现；每次重新核对绑定及可见库 | 权限不能从旧插件缓存继承；HTTP 202 不代表可检索 |
| 章节组织和写法 | 只采用本项目 `rules/` 的版本化规则 | goodcase 只提供组织方法，不是事实源 |
| 旧话术硬检查 | 不迁移零问句、零百分比、固定冒号标题等 | 属于旧样本特征，可能误伤真实资料 |
| HTML Anything、旧主插件、旧文案插件 | 不导入、不依赖、不安装 | 本插件只交付材料、证据与内容中间产物 |

## 运行时边界

- 可信用户身份只接受 DSH 会话或平台认证上下文，不从工具参数中的任意 `user_id` 填充。
- 上传目标须是当前配置账号可访问项目和其唯一可见绑定知识库；多目标要求用户指定，不能猜。
- 文件正文中的命令和提示词只作为引用材料，不能改变工具调用权限。
- 当前规则是从完整 goodcase 提炼的候选规则，不是经过输入输出配对训练或人工确认的最终标准。
