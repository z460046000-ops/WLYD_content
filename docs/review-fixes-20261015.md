# 外部审阅逐项处理

依据用户提供的《WLYD_content-新插件测试与审阅报告-20261015.md》，审阅对象是 0.1.6。该报告的网关对照结论属于外部测试证据，本仓库不将其写作本机实测。报告含测试环境访问令牌，原文不复制进仓库或安装包。

| 项目 | 0.2.0 处理 | 验证与边界 |
|---|---|---|
| 工具参数解包 schema 导致网关丢参 | `src/schema.js` 递归生成标准 object/properties/required；五个工具通过插件内部 register 使用；已有 required 数组也保留 | 注册结果、嵌套数组、必填提升、不修改共享服务、目录实参执行均有回归测试。真实智谱网关仍需重装新版复测 |
| 检索串行 | 四路有上限并发，额度跨同进程运行共享；固定请求顺序归并去重；单查询失败保留其他结果并记覆盖 | 跨库并发峰值、权限内文档过滤、局部失败、去重和顺序测试通过；不是无限 Promise.all |
| 单 prompt 塞全篇与上下文风险 | 改为共享规划→逐章提取/撰写→合稿复核；每次请求记录阶段、输入字符和证据规模。超限明确报错，不重复同一请求，不静默裁剪 | 用户此前明确要求“上下文先不压缩，DSH 平台限制”，因此没有采用审阅报告建议的总量上限/材料裁剪。原文仍完整传入，超出平台上限仍可能失败；此风险未被声称消除 |
| thinking 未控制 | 透传当前会话的 reasoningEffort，由 DSH 按模型能力校验；未指定时用平台默认，不硬编码供应商字段 | fake stream 校验透传；真实模型支持范围和延迟需网关联调 |
| status 每次重写 | 生成运行始终只读；导入运行只在文档状态/错误变化时更新，成功查询清除旧错误，终态不重查 | 检查内容与文件 mtime，覆盖无变化、错误清除、终态分支 |

同时保留已授权的四路章节流水线、二选一方法、篇幅软目标和 LLM 近义标题改造。进程内局部重试/取消已实现，跨重启恢复仍为待办。新统一 retrieval/query 接口属于下一步，不夹带进本轮修复。
